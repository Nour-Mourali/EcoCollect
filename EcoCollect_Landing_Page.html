1 · Idea and need

Waste gets reported in one place and handled in another

EcoCollect closes that gap, so problems are visible from the first report to the final impact.

Overflowing bins

Citizens don't know where to report a full container, or whether anyone acted.

Illegal dumping

Reports often lack a precise location, evidence or a clear follow-up.

Uncoordinated collection

Field teams need assignment, scheduling and status tracking.

Hidden impact

Without consolidated indicators, nobody can show what was collected or recycled.

Where we drew the line

Notifications are centralized

One shared service turns events into notifications with read and unread status. In-app is the main channel, and email is an optional preference.

CO₂ is an estimate

Savings come from documented coefficients and recorded quantities. The dashboard never claims scientific precision.

Pickups where available

Citizens can request a pickup only where a collection service operates. Anyone can file a report.

Keycloak handles sign-in and issues JWT tokens. Roles separate citizens, agents, center managers and administrators. The token's sub is the user ID everywhere.

3 · Architecture: security

One door in, and every request carries a token

Keycloak signs people in. The gateway checks every request before routing it, and the services stay in the private network.

How a request is secured

  1. Sign in on the Keycloak pageAuthorization Code with PKCE.
  2. The app receives an access token (JWT) and a refresh token
  3. Each request carries Authorization: Bearer <JWT>
  4. The gateway downloads Keycloak's public keys once and caches them
  5. The gateway checks signature, expiry, issuer and roleNo call to Keycloak per request.
  6. It routes to the service, for example lb://COLLECTION-SERVICE, with the token forwarded
  7. The service answers through the gateway
  8. Errors are explicit401 for a missing or bad token, 403 for the wrong role.

Realm ecocollect, public client ecocollect-front.

  • Interested services consume it on their own.
  • Analytics and notifications react without blocking the producer.

Risks we are watching

  • Six services must integrate through shared events and security.
  • Duplicate events could award points twice, so consumers must be idempotent.
  • If Recycling is down, Collection completes the task without a proposed center instead of failing.
  • CO₂ coefficients need a documented source.
